# Missing Exhibit

The lights go out. A raccoon takes one treasure. Pick what is missing from the display.

Tap **Start case**. Watch the cabinet, then pick an exhibit. Recover all three to finish a gallery. First guesses determine the medal, and every completed case unlocks the next gallery. The map lets you revisit all six galleries. A new case deals a fresh assortment of objects. The choices have no time limit. On a keyboard, use Tab and Enter, or 1–4 to choose an answer.

Open `index.html` or `standalone.html` directly. Both files include the artwork, gameplay, and synthesized audio. To rebuild after editing the source, run `node build.cjs`. The design and all illustrations were drawn for this game. The art uses SVG, brass framing, and layered light, with no external asset requests.

The Table Memory challenge in [ALMOST!](https://combos.game/zh-CN/play/c1cad8f9fe2569274a66ec02cf850a34) by ライム inspired the short preview and item-selection structure.
